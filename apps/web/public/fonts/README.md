# Fonts

SRPanel uses **Vazirmatn** (SIL Open Font License) self-hosted from this folder:

- Vazirmatn-Regular.woff2
- Vazirmatn-Medium.woff2
- Vazirmatn-SemiBold.woff2
- Vazirmatn-Bold.woff2

If the `.woff2` files are missing (e.g. after a text-only git push), download them from
https://github.com/rastikerdar/vazirmatn/releases (folder `fonts/webfonts/`) and place them here.
The UI falls back to the system font stack until they exist.
