# SRPanel ⚡

**پنل ابری مدیریت نمایندگی VPN (چندسرور 3x-ui) — امن، سریع، بی‌مرز**

نسخه کاستوم‌شده بر پایه [hmpanel v2.1.1](https://github.com/neoauroraproject/hmpanel) با تم اختصاصی «دارک لوکس» (گلس‌مورفیسم + نئون).

> ⚠️ **این ریپو یک Overlay است** — فقط فایل‌های تغییرکرده/جدید نسبت به سورس پایه hmpanel v2.1.1 اینجا نگهداری می‌شوند. برای بیلد کامل، این فایل‌ها را روی سورس پایه کپی کنید.

## تغییرات

### فاز ۰ — پایه‌سازی بک‌اند (Self-hosted)
- حذف کامل وابستگی به سرور لایسنس؛ اکتیویشن و هارت‌بیت به‌صورت آفلاین/لوکال
- آنلاک همه ماژول‌ها و فیچرهای پرمیوم برای همه ادمین‌ها (فروشگاه، برندینگ، مانیتورینگ پرو، بکاپ‌سنتر، کاستوم دامین، تمپلیت کلاینت، شارژ ادمین و…)
- پیاده‌سازی کامل سرویس‌های فروشگاه (احراز هویت مشتری، نوتیفیکیشن، Rate-limit، کانفیگ پرداخت) و ماژول برندینگ

### فاز ۱ — دیزاین‌سیستم SRPanel (فرانت‌اند)
- تم «دارک لوکس»: گلس‌مورفیسم، گرادیان بنفش→سایان، افکت‌های نئون، پشتیبانی کامل RTL
- بازطراحی لاگین، داشبورد، سایدبار، ناوبری موبایل، AppShell و کیت UI
- ری‌برندینگ کامل به **SRPanel** در رابط کاربری و فایل‌های ترجمه (fa/en)

## نحوه استفاده

1. سورس پایه hmpanel نسخه **2.1.1** را تهیه کنید.
2. فایل‌های این ریپو را با حفظ ساختار پوشه‌ها روی سورس پایه کپی (Overwrite) کنید.
3. بیلد:

</div>

```bash
# Backend (NestJS)
cd backend && npm install && npm run build

# Frontend (Next.js 16)
cd frontend && npm install && npm run build
```

## ساختار تغییرات

| مسیر | توضیح |
| --- | --- |
| `backend/src/platform/` | لایسنس و اکتیویشن Self-hosted |
| `backend/src/premium-modules/store/` | سرویس‌های کامل فروشگاه |
| `backend/src/premium-modules/branding/` | ماژول برندینگ (جدید) |
| `backend/src/common/guards/` و `premium-module.guard.ts` | آنلاک گاردهای پرمیوم |
| `backend/src/app.module.ts` | وایرینگ ماژول‌های جدید |
| `frontend/src/app/globals.css` | دیزاین‌توکن‌های تم دارک لوکس |
| `frontend/src/components/` | AppShell، سایدبار، کیت UI بازطراحی‌شده |
| `frontend/src/app/(app)/dashboard/page.tsx` | داشبورد جدید |
| `frontend/src/app/login/page.tsx` | صفحه ورود جدید |
| `frontend/src/i18n/messages/` | استرینگ‌های برند SRPanel (fa/en) |

> فایل‌های باینری (لوگو، فونت‌ها، تصاویر) از طریق API متنی قابل پوش نیستند؛ پکیج کامل نصب به‌صورت zip جداگانه تحویل شده است.
